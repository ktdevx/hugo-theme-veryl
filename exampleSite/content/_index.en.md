## Build sites that keep attention on the content

Veryl is a Hugo theme that puts writing and information first.

It keeps the structure calm and the navigation clear so your content can be understood without distractions.

## Good fits

- Personal profiles and portfolios
- Small team or project sites
- Blogs centered on reading
- Documentation sites that need to last

## What it values

### Clarity

Readers should be able to see where they are and what to read next.

### Focus

Content should stay readable before the design or features grow.

### Room to grow

Start small, then extend the structure and presentation as the site evolves.

## Current status

Veryl is still under development. The theme structure, supported layouts, and configuration are being refined as the experience takes shape.

This page will continue to evolve alongside the theme as new features are added.

## Getting started

Add Veryl to your Hugo site and set the theme in `hugo.toml`.

```toml
theme = "veryl"
```

See the repository [README](https://github.com/ktdevx/hugo-theme-veryl) for the full setup guide.
